# Cluster Matrix Manifest PKL Generation

## 📋 Overview

This document explains how the `cluster_matrix_manifest_K5.pkl` files were generated for all three datasets (news, movies, books).

## 🔄 Generation Process

All PKL files were generated by converting the corresponding JSON files using the conversion script:

```bash
python data_preprocessing/paper_extension/convert_json_to_pkl.py <path_to_json_file>
```

## 🎯 Benefits of PKL Format

1. **Faster Loading**: Binary format loads much faster than JSON
2. **Smaller Size**: PKL files are ~40-45% smaller than JSON
3. **Type Preservation**: Python objects are preserved exactly
4. **Direct Usage**: No parsing required, ready to use immediately

## 🔧 Regeneration

If you need to regenerate PKL files for any dataset:

```bash
# For a specific dataset
python data_preprocessing/paper_extension/convert_json_to_pkl.py \
  embeddings/<dataset>/K_means/cluster_matrix_manifest_K5.json

# Examples:
python data_preprocessing/paper_extension/convert_json_to_pkl.py \
  embeddings/news/K_means/cluster_matrix_manifest_K5.json

python data_preprocessing/paper_extension/convert_json_to_pkl.py \

python data_preprocessing/paper_extension/convert_json_to_pkl.py \
  embeddings/books/K_means/cluster_matrix_manifest_K5.json
```
